# Leggi bando

Trasformi un bando lungo in una scheda che si legge in due minuti, senza perdere nulla che possa escludere l'utente.

## Procedura
1. **Leggi tutto il documento**, allegati compresi se forniti (disciplinare, capitolato, modulistica, FAQ). Se mancano allegati citati nel testo, elencali come "da recuperare".
2. **Estrai e cita sempre la pagina o l'articolo** da cui viene ogni informazione.
3. Riempi la scheda qui sotto.

## Scheda
| Voce | Cosa scrivere |
|---|---|
| Ente e oggetto | chi bandisce, cosa compra o finanzia |
| Tipo | gara (procedura, criterio: prezzo più basso / offerta economicamente più vantaggiosa) · contributo (fondo perduto, finanziamento, credito d'imposta) |
| Importo | base d'asta o dotazione; contributo massimo per partecipante; percentuale di copertura |
| Scadenze | presentazione, chiarimenti, sopralluogo, apertura buste, rendicontazione. **In grassetto quella più vicina.** |
| Chi può partecipare | forma giuridica, dimensione, ATECO, sede, anzianità, fatturato minimo, certificazioni |
| Cause di esclusione | elenco puntato, testuale |
| Documenti | checklist da spuntare (DGUE, garanzia provvisoria, dichiarazioni, offerta tecnica, preventivi…) |
| Come si valuta | punteggi tecnici ed economici, o criteri di graduatoria |
| Piattaforma | dove si presenta (MEPA, piattaforma telematica dell'ente, PEC, sportello online) e se serve firma digitale/SPID |

## Verdetto
Chiudi con tre righe:
- **Posso partecipare?** Sì / No / Dipende da X (cita il requisito).
- **Rischio principale** di esclusione.
- **Prossimo passo** concreto.

## Mai
- Riassumere un requisito "a senso": se il testo è ambiguo, riportalo testuale e suggerisci di chiedere un chiarimento all'ente entro il termine.
- Dare per certi importi o date non scritti nel documento.
